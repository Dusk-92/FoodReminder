# 🍖 FoodReminder

Fenêtre de raccourcis configurable pour regrouper nourriture, boissons, consommables et autres raccourcis utiles dans LOTRO.

**🌍 Langues / Languages / Sprachen :** 🇫🇷 Français · 🇬🇧 English · 🇩🇪 Deutsch

---

## 🇫🇷 Français

### 📖 Présentation

**FoodReminder** regroupe des raccourcis LOTRO dans une petite fenêtre configurable afin de garder facilement sous la main nourriture, boissons, consommables ou autres actions utiles.

### ✨ Fonctionnalités

- Cases de raccourcis configurables par glisser-déposer.
- Suppression d’un raccourci au clic droit ou à la molette lorsque les cases sont déverrouillées.
- Icône flottante pour afficher ou masquer la fenêtre.
- Accès rapide aux options depuis l’icône.
- Verrouillage/déverrouillage des raccourcis.
- Position et réglages mémorisés.
- Interface FR / EN / DE.
- Compatibilité avec les anciennes sauvegardes FoodReminder / FoodAndDrinks.

### 📦 Installation

Copie le dossier **Dusk** dans :

```text
Documents\The Lord of the Rings Online\Plugins\
```

Puis en jeu :

```text
/plugins refresh
/plugins load FoodReminder
```

### 🎮 Utilisation

- Glisse un raccourci dans une case.
- **Clic gauche sur l’icône** : afficher/masquer FoodReminder.
- **Clic droit sur l’icône** : ouvrir les options.
- **Maj + clic gauche sur l’icône** : verrouiller/déverrouiller les raccourcis.
- Lorsque les cases sont déverrouillées, clic droit ou molette sur une case pour retirer son raccourci.

### ⌨️ Commandes

- `/Fo help` — afficher l’aide et les commandes disponibles.

### ⚙️ Sauvegardes & réglages

FoodReminder conserve volontairement la clé historique `FoodAndDrinks_Settings` pour préserver les anciens raccourcis et réglages. Le plugin utilise également son propre espace Lua pour isoler ses données.

### 🌍 Langues

L’interface est disponible en **français, anglais et allemand**.

### ⚠️ Limites / notes

FoodReminder fournit des raccourcis : il n’automatise pas l’utilisation des consommables et laisse les actions au joueur.

### 🐛 Bugs & suggestions

Utilise les [Issues GitHub](https://github.com/Dusk-92/FoodReminder/issues).

### 🙏 Crédits

Développement et maintenance : **Dusk-92**.

## 🇬🇧 English

### 📖 Overview

**FoodReminder** groups LOTRO shortcuts into a small configurable window so food, drinks, consumables and other useful actions stay easy to reach.

### ✨ Features

- Configurable shortcut slots with drag and drop.
- Remove shortcuts with right-click or middle mouse when slots are unlocked.
- Floating icon to show or hide the window.
- Quick access to options from the icon.
- Lock/unlock shortcut slots.
- Saved position and settings.
- FR / EN / DE interface.
- Compatibility with older FoodReminder / FoodAndDrinks saved data.

### 📦 Installation

Copy the **Dusk** folder into:

```text
Documents\The Lord of the Rings Online\Plugins\
```

Then in game:

```text
/plugins refresh
/plugins load FoodReminder
```

### 🎮 Usage

- Drag a shortcut into a slot.
- **Left-click the icon**: show/hide FoodReminder.
- **Right-click the icon**: open options.
- **Shift + left-click the icon**: lock/unlock shortcuts.
- When slots are unlocked, right-click or middle-click a slot to remove its shortcut.

### ⌨️ Commands

- `/Fo help` — display help and available commands.

### ⚙️ Saved data & settings

FoodReminder intentionally keeps the historical `FoodAndDrinks_Settings` key so existing shortcuts and settings remain compatible. The plugin also uses its own Lua data apartment.

### 🌍 Languages

The interface is available in **English, French and German**.

### ⚠️ Limitations / notes

FoodReminder provides shortcuts only. It does not automate consumable use and leaves every action under player control.

### 🐛 Bugs & suggestions

Use [GitHub Issues](https://github.com/Dusk-92/FoodReminder/issues).

### 🙏 Credits

## 🇩🇪 Deutsch

### 📖 Übersicht

**FoodReminder** bündelt LOTRO-Verknüpfungen in einem kleinen konfigurierbaren Fenster, damit Nahrung, Getränke, Verbrauchsgegenstände und andere Aktionen schnell erreichbar bleiben.

### ✨ Funktionen

- Konfigurierbare Felder per Drag & Drop.
- Verknüpfungen per Rechtsklick oder mittlerer Maustaste entfernen, wenn die Felder entsperrt sind.
- Schwebendes Symbol zum Ein-/Ausblenden des Fensters.
- Schneller Zugriff auf die Optionen über das Symbol.
- Verknüpfungen sperren/entsperren.
- Gespeicherte Position und Einstellungen.
- Oberfläche auf FR / EN / DE.
- Kompatibilität mit älteren FoodReminder-/FoodAndDrinks-Speicherdaten.

### 📦 Installation

Den Ordner **Dusk** nach folgendem Pfad kopieren:

```text
Documents\The Lord of the Rings Online\Plugins\
```

Danach im Spiel:

```text
/plugins refresh
/plugins load FoodReminder
```

### 🎮 Verwendung

- Eine Verknüpfung in ein Feld ziehen.
- **Linksklick auf das Symbol**: FoodReminder anzeigen/ausblenden.
- **Rechtsklick auf das Symbol**: Optionen öffnen.
- **Umschalt + Linksklick**: Verknüpfungen sperren/entsperren.
- Bei entsperrten Feldern Rechtsklick oder mittlere Maustaste verwenden, um eine Verknüpfung zu entfernen.

### ⌨️ Befehle

- `/Fo help` — Hilfe und verfügbare Befehle anzeigen.

### ⚙️ Gespeicherte Daten & Einstellungen

FoodReminder behält absichtlich den historischen Schlüssel `FoodAndDrinks_Settings`, damit bestehende Verknüpfungen und Einstellungen erhalten bleiben. Zusätzlich verwendet das Plugin einen eigenen Lua-Datenbereich.

### 🌍 Sprachen

Die Oberfläche ist auf **Deutsch, Englisch und Französisch** verfügbar.

### ⚠️ Einschränkungen / Hinweise

FoodReminder stellt nur Verknüpfungen bereit. Verbrauchsgegenstände werden nicht automatisch benutzt.

### 🐛 Fehler & Vorschläge

Bitte die [GitHub Issues](https://github.com/Dusk-92/FoodReminder/issues) verwenden.

Entwicklung und Wartung: **Dusk-92**.
